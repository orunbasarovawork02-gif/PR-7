# PR-7. Тур-гид по Астане

Сайт показывает достопримечательности Астаны. Данные больше не хранятся в файле `data.json`. Чтение и сохранение идут через запросы к облачной базе MongoDB Atlas, поэтому сайт может работать с одними и теми же данными с любого компьютера.

Страницы, шаблоны и форма добавления остались как в ПР 6. Изменился только источник данных.

## Что изменилось

| | Было в ПР 6 | Стало в ПР 7 |
|---|---|---|
| Где данные | Файл `data.json` | Облачная база MongoDB Atlas |
| Чтение | `fs.readFileSync` | Запрос к базе `find()` |
| Сохранение | `fs.writeFileSync` | Запрос к базе `insertOne()` |

## Как устроен проект

- `project/db.js` — подключение к MongoDB
- `project/server.js` — маршруты сайта
- `project/test-db.js` — проверка строки подключения
- `project/seed.js` — разовый перенос записей из `data.json` в базу
- `project/.env` — строка подключения, файл не попадает в git
- `project/views` — шаблоны страниц

База называется `cinema`, коллекция — `places`.

## Запуск

1. Зарегистрируйтесь на [MongoDB Atlas](https://www.mongodb.com/cloud/atlas) и создайте бесплатный кластер.
2. Создайте пользователя базы и разрешите доступ с любого IP (`0.0.0.0/0`).
3. Скопируйте строку подключения в `project/.env`:

```
MONGODB_URI=mongodb+srv://user:pass@cluster0.xxxxx.mongodb.net/
```

4. Установите зависимости и проверьте соединение:

```
cd project
npm install
npm run test-db
```

В консоли должно появиться: `подключение работает`.

5. Один раз перенесите старые записи из файла в облако:

```
npm run seed
```

6. Запустите сайт:

```
npm start
```

Откройте http://localhost:3000

## Маршруты

- `GET /` — список мест из базы
- `GET /place/:id` — подробная страница места
- `GET /add` — форма добавления
- `POST /add` — сохранение новой записи в MongoDB
- `GET /about` — страница о проекте

Если связь с облачной базой пропадет, сайт покажет страницу ошибки, а не упадет без сообщения.
